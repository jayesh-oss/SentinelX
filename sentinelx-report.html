Transfer Learning Strategy
Progressive fine-tuning in two phases
Phase 1 — Epochs 1–5
Frozen Backbone
All EfficientNet layers frozen. Only the custom classifier head (338K params) trains at LR = 0.001. Fast convergence from ImageNet features.
Fine-tune Trigger — Epoch 6
Last 2 Blocks Unfrozen
Blocks 7–8 unlocked. Backbone LR set to 0.0001 (0.1× classifier). Allows domain-specific low-level feature adaptation.
Result — Epoch 15
85.0% Validation Accuracy
+8.4% gain from fine-tuning. Final model: 16.8 MB. Training completed in 8.4 minutes on RTX 5060.
Data Augmentation
RandomHorizontalFlip · RandomRotation(5°) · ColorJitter
WeightedRandomSampler + weighted CrossEntropyLoss for class imbalance
